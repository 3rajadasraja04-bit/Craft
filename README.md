# ⚡ ZHD Nexus Command Deck

Full-stack web control panel for the ZHD bot engine. Ultra cyberpunk UI + FastAPI backend + Railway deploy ready.

## Stack
- **Backend**: FastAPI + Uvicorn
- **Frontend**: Pure HTML/CSS/JS (no build step)
- **Realtime**: WebSocket state stream @ 0.8s
- **Bot engine**: `vn.py` (untouched — wrapped, not modified)
